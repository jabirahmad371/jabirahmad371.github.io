# Simple PhD Portfolio

A minimal academic website for PhD applications.

## Included
- About
- Education
- Research
- Selected publications
- Selected projects
- Research interests
- CV and profile links

## Add your profile photo

Put your photo in:

`assets/profile.jpg`

Then replace this in `index.html`:

`assets/profile-placeholder.svg`

with:

`assets/profile.jpg`

## Publish

Upload all files to the root of:

`jabirahmad371.github.io`

Then enable GitHub Pages from:

**Settings → Pages → Deploy from a branch → main → /(root)**


## Included visual assets

- `assets/profile.jpg` — profile photo
- `assets/iut-logo.png` — IUT logo
- `assets/ndc-logo.png` — Notre Dame College logo

The institution logos are displayed inside white boxes for contrast on the dark theme.
