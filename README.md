# Jabir Ahmad Jahin Bhuiyan — Portfolio

Personal academic and research portfolio hosted with GitHub Pages.

## Live site

After GitHub Pages is enabled, the site will be available at:

`https://jabirahmad371.github.io/`

## Files

- `index.html` — website content
- `style.css` — styling and responsive design
- `script.js` — navigation and small interactive behavior
- `assets/Jabir_Ahmad_Jahin_Bhuiyan_CV.pdf` — CV used by the website

## Publish on GitHub Pages

1. Create a **public** repository named exactly `jabirahmad371.github.io`.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
5. Save the settings.

No `_config.yml` file is required for this site.
